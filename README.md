# Painel Financeiro

Painel visual para a **Planilha de Planejamento Financeiro**: mostra saldo do mês, entradas, saídas, taxa de poupança, maiores gastos por categoria, evolução no ano, reserva de emergência e meta de investimento — sem precisar abrir fórmulas.

**Acesse:** https://bialehmanns-gif.github.io/painel-financeiro/

## Como usar

1. Lance entradas e saídas na planilha, como de costume.
2. Salve o arquivo em .xlsx (no Google Sheets: *Arquivo › Fazer download › Microsoft Excel (.xlsx)*).
3. Abra o painel e arraste o arquivo para a tela, ou clique em **Abrir planilha**.
4. Para conhecer sem ter uma planilha, clique em **Ver exemplo**.

## Privacidade

A planilha é lida **no seu navegador**: nenhum dado é enviado para a internet ou para este repositório.

## Arquivos

- `index.html` — o painel completo em um único arquivo (estilos, fontes e scripts embutidos).
